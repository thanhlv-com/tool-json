# JSON Dev Tool

Vite + React + TypeScript app for formatting, validating, diffing, querying, and converting JSON in the browser.

## Run Locally

Prerequisites: Node.js

1. Install dependencies:
   `npm ci`
2. Start development server:
   `npm run dev`

## Build

1. Type-check:
   `npm run lint`
2. Create production build:
   `npm run build`
